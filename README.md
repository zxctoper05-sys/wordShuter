# Word Shooter

Браузерный тайпинг-шутер: слова падают сверху, вы печатаете их — пушка внизу стреляет.
Русский и английский словари (десятки и сотни тысяч слов из открытых источников в PostgreSQL),
4 режима игры, статистика и личные рекорды, адаптивный интерфейс с экранной клавиатурой.

**Стек:** HTML5 + CSS3 + ванильный JS (ES-модули) + Canvas · Node.js + Express (REST) · PostgreSQL.
Без React, Bootstrap и Tailwind.

## Быстрый старт

Нужны Node.js ≥ 18 и PostgreSQL ≥ 13.

```bash
# 1. База данных
createdb wordshooter              # или через psql / pgAdmin

# 2. Зависимости и настройки
npm install
cp .env.example .env              # поправьте DATABASE_URL под свою БД

# 3. Схема + словари (нужен интернет один раз)
npm run setup                     # = migrate + dict:download + dict:import

# 4. Запуск
npm start                         # http://localhost:3000
```

`npm run setup` скачивает словари в `data/raw/` и импортирует их в БД; импорт русского
словаря (≈1,5 млн словоформ) занимает 1–3 минуты. Если нужна компактная база — импортируйте
только частотные слова: `npm run dict:import -- --common-only`.

### Docker

```bash
docker compose up -d --build
docker compose exec app npm run setup
# http://localhost:3000
```

## Как играть

Слова нужно набирать целиком — как только слово набрано, пушка стреляет по нему. Мышь не нужна:
поле ввода всегда в фокусе. Неверная буква не принимается (комбо сбрасывается, точность падает),
Backspace стирает. Регистр не важен, «ё» набирается как «е». `Esc` — пауза.

| Режим | Правила |
|---|---|
| Классика | 5 жизней, 10 уровней по 12 слов, всё быстрее. Пройдите все 10 — победа. |
| Выживание | 3 жизни, уровень растёт каждые 20 секунд, игра идёт до последней жизни. |
| На время | 90 секунд, 5 жизней, максимум очков. |
| Бесконечный | Игра не заканчивается: потеряли все жизни — получаете «второе дыхание» (жизни восстановлены, сложность −2 уровня, поле очищено). Завершить забег можно из паузы. |

Очки за слово: `длина × 10 × множитель`, множитель комбо растёт на 1 за каждые 5 слов подряд (до ×8).
Слово у земли — минус жизнь и сброс комбо. WPM считается по стандарту (5 символов = 1 слово, пробел учитывается).

Язык интерфейса (по умолчанию русский) и язык слов — независимые настройки; обе сохраняются в браузере
и переключаются без перезагрузки.

## Структура проекта

```
server/                 Express: app.js (приложение), index.js (запуск), routes/api.js,
  services/             words.js (выборка слов), stats.js (результаты игр), validate.js, middleware.js
db/                     migrate.js + migrations/*.sql (схема версионируется)
scripts/                download-dictionaries.js, import-dictionary.js, dictionaries.config.js, lib/ (правила слов, фильтр)
public/                 клиент без сборки
  js/core/              api.js · i18n.js · storage.js · stats.js · bus.js (шина событий)
  js/locales/           ru.js, en.js — все тексты интерфейса
  js/game/              engine.js (логика) · difficulty.js · collision.js · words.js (подгрузка слов)
                        effects.js (частицы, тряска) · renderer.js (Canvas) · session.js (цикл rAF) · layouts.js
  js/ui/                экраны: меню, игра, итоги, статистика; экранная клавиатура
tests/                  node --test: движок, сложность, коллизии, правила слов, валидация API
```

Движок (`engine.js`) — чистая логика без DOM: он публикует события (`kill`, `hit`, `miss`, `level`, `gameover` …)
в шину, а эффекты, HUD и будущий звук просто подписываются на них.

## Словари

Источники (скачиваются скриптом, в репозиторий не входят):

| Язык | Полный словарь | Частотный список (флаг «частое слово») |
|---|---|---|
| English | [dwyl/english-words](https://github.com/dwyl/english-words) (`words_alpha`) | [google-10000-english](https://github.com/first20hours/google-10000-english) |
| Русский | [danakt/russian-words](https://github.com/danakt/russian-words) (cp1251 → UTF-8) | [hingston/russian](https://github.com/hingston/russian) (30 000 самых частых) |
| оба | список нежелательных слов [LDNOOBW](https://github.com/LDNOOBW/List-of-Dirty-Naughty-Obscene-and-Otherwise-Bad-Words) | |

Перед публикацией проекта проверьте лицензии источников.

Что делает импорт: приводит слова к нижнему регистру; оставляет только буквы нужного алфавита длиной 3–14
с гласной; убирает дубликаты, тройные повторы и слова из блок-листа; считает сложность 1–5
(по длине слова, +1 за две и более редкие буквы); частотные слова сверяет с полным словарём (отсекает опечатки
и сокращения). Игра по умолчанию использует только частотные слова — это переключается в настройках.

Игровая сессия получает слова пачками через `POST /api/words/batch` и никогда не обращается к внешним
словарям; повторы в рамках сессии исключены (клиент передаёт id уже выданных слов).

```bash
npm run dict:import -- --lang=ru --truncate          # переимпорт одного языка
npm run dict:import -- --lang=en --file=./my.txt --common --source=my-list   # свой список слов
```

**Добавить язык:** запись в `scripts/dictionaries.config.js`, правила алфавита в `scripts/lib/wordRules.js`,
раскладка в `public/js/game/layouts.js`, кнопка языка в `public/index.html`, код языка в `server/constants.js`.

## REST API

| Метод | Путь | Назначение |
|---|---|---|
| GET | `/api/health` | проверка сервера и БД |
| GET | `/api/dictionaries` | число слов по языкам |
| POST | `/api/words/batch` | `{lang, difficulty 1–5, count, maxLength, commonOnly, exclude:[id]}` → `{words:[{id, word}]}` |
| POST | `/api/games` | сохранить результат игры → `{id, records:{score, wpm, combo}}` |
| GET | `/api/players/:uuid/stats` | итоги, рекорды по режимам/языкам, последние игры |

Игрок пока анонимный: UUID создаётся в браузере (`localStorage`). Результат, который не удалось отправить,
ставится в очередь и уходит при следующем запуске.

## Деплой

Любой хостинг с Node.js ≥ 18 и PostgreSQL:

1. Задайте переменные окружения: `DATABASE_URL`, `PORT`, `NODE_ENV=production`; для управляемых БД
   с SSL — `PGSSL=true`; за nginx/балансировщиком — `TRUST_PROXY=1`.
2. Один раз выполните `npm run migrate && npm run dict:download && npm run dict:import`.
3. Запустите `npm start` (под systemd, pm2 или в контейнере). Статика отдаётся тем же процессом.
4. Перед `npm start` при каждом обновлении выполняйте `npm run migrate` — он применяет только новые миграции.

Пример nginx: `proxy_pass http://127.0.0.1:3000;` плюс `proxy_set_header X-Forwarded-For $remote_addr;`.
